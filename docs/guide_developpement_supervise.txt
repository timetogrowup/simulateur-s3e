PÉRIMÈTRE FIGÉ
Trois intitulés : Situation actuelle / Demain avec une voiture de fonction / Demain sans voiture de fonction.
Questionnaire rapide dynamique ; premier bilan ; affinage prérempli ; recalcul uniquement au clic ; bilan affiné ; sauvegarde et export ; aucune collecte de données du salarié.
Seul l'impact estimé en cotisations et impôt de l'AEN compte comme coût, pas le brut. Sur le futur véhicule électrique SUEZ, le salarié paie les recharges effectuées à domicile ET les bornes publiques payantes sans prise en charge par SUEZ ; les recharges effectivement couvertes par SUEZ restent gratuites pour lui. Référentiels AEN, compensation et consommations : FICTIFS, non officiels.

LOT SUIVANT — SAUVEGARDES NOMMÉES V2 (EVOL-SAVE-001)
Date : 17/10/2026
Objectif : permettre plusieurs simulations indépendantes dans le navigateur, leur reprise et la suppression individuelle.
État : développé, recette automatisée en cours de vérification à la rédaction.

RÈGLES RETENUES
- Stockage local uniquement : clé s3e-simulations-v2, format versionné schemaVersion=2.
- Maximum 20 simulations par navigateur ; titre fourni par le salarié (100 caractères maximum).
- Chaque simulation contient réponses, étape, vue, estimation, valeurs affinées et bilan affiné éventuel.
- Consultation des simulations depuis « Reprendre une sauvegarde » à l’accueil.
- Chaque entrée peut être reprise ou supprimée après confirmation.
- Les noms sont échappés dans le HTML : un titre ne doit pas injecter du code.
- L'ancienne clé s3e-mobile-test est migrée si aucune sauvegarde V2 n’existe et l’original est conservé.
- Une donnée corrompue est refusée sans effacement automatique ; les erreurs sont signalées.
- Les données restent sur le navigateur ; elles peuvent disparaître avec les données locales et ne sont pas synchronisées.

CODE CIBLÉ
- index.html : snapshot(), validSnapshot(), readSaves(), storeSaves(), migrateLegacy(), save(), load(), restoreSave(), removeSave(), savesPage(), escapeHtml().
- tests/smoke.cjs : sauvegardes multiples, reprises indépendantes, suppression, format invalide, ancienne sauvegarde, écran de gestion.

LIMITES ET VIGILANCES
- Pas encore de sauvegarde JSON téléchargeable, d'import ni de synchronisation multi-appareils.
- Les résultats enregistrés peuvent reposer sur des hypothèses fiscales fictives anciennes ; une future reprise devra gérer explicitement le schéma et la version des référentiels.
- Le schéma de validation est provisoire ; le rendre plus strict lors de la modularisation.
- Tests navigateur réel et mobile à faire en complément de la CI.

LOT EVOL-RECHARGE-002 — RECHARGES PUBLIQUES PAYANTES
Date : 17/10/2026
Décision : les bornes publiques payantes sans prise en charge SUEZ sont à la charge du salarié. Lorsque le domicile ne permet aucune recharge, la totalité des recharges hors domicile est estimée payante pour le salarié dans le prototype, avec un tarif public à saisir.
Calcul : km × consommation kWh/100 × [part domicile × tarif domicile + (1-part domicile) × part publique payante × tarif public].
Les bornes et cartes effectivement financées par SUEZ ne créent aucun coût pour le salarié.
Implémentation : index.html, tests/smoke.cjs. Fiche spécifique : docs/evolutions/EVOL-RECHARGE-002_recharge_publique_payante.txt.
Contrôles : conditions d’affichage, calcul 100 % public payant, moitié payante, recharge SUEZ gratuite, non-régression du bilan.
Limites : valeurs tarifaires fictives ; traitement des versions de sauvegardes anciennes à fiabiliser.

CLÔTURE TECHNIQUE EVOL-RECHARGE-002
Tests de cohérence GitHub Actions : réussis le 17/10/2026.
La restauration d'un ancien bilan affiné recalcule ses résultats avec les nouvelles règles, pour éviter l'affichage d'un ancien coût de recharge extérieure nul. Valeurs manquantes des anciens dossiers affinés prises par défaut.
Recette visuelle sur téléphone et validation des tarifs publics encore à effectuer. Aucun montant officiel SUEZ n'est intégré.

AJUSTEMENT EVOL-RECHARGE-002 — TARIF PUBLIC AUTOMATIQUE
17/10/2026 : si aucune recharge à domicile n'est possible, la question sur le prix des bornes publiques est masquée ; 100 % des recharges sont supposées payées personnellement et chiffrées par défaut à 0,50 €/kWh (hypothèse fictive issue du référentiel). Le prix se modifie seulement lors de l'affinage. Les valeurs publiques sauvegardées dans le questionnaire rapide ne prévalent pas sur ce défaut.
Fichiers : index.html, tests/smoke.cjs, docs/evolutions/EVOL-RECHARGE-002_recharge_publique_payante.txt.
